# Tarelika Updates / Обновления «Тарелики»

Публичный **канал обновлений**, без исходников приложения, пользовательских рецептов, ключей подписи и настроек Nexum.

- `manifest.json` — текущая версия Android-приложения и список изменений.
- `tarelika-*.apk` — готовые APK, подписанные соответствующим ключом (на время испытаний **только debug APK**).
- `RELEASES.md` — журнал публикаций и порядок подготовки версии.

Клиент Android читает HTTPS:
`https://raw.githubusercontent.com/TheLane/Tarelika-Updates/main/manifest.json`

Для тестового APK использован стандартный debug-ключ машины разработчика: не устанавливать поверх production APK с другим сертификатом. При обновлении Android проверяет совпадение подписи и `applicationId=com.lanesoftware.tarelika`.

Выпуски доступны всем: **не хранить здесь приватные данные, токены, исходники, ключи подписи или файлы SQLite**.

Источники «Тарелики» ведутся в отдельном проекте; этот репозиторий содержит только публичные дистрибутивы и манифест.
