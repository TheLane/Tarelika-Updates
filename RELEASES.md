# Выпуски «Тарелики»

## 0.5.5 — тестовое обновление через GitHub (Android, код 14)

- В настройках обновлений отображается установленная версия приложения.
- Манифест автоматически проверяется по публичному HTTPS-адресу GitHub Raw, если в настройках включена автоматическая проверка.
- APK `tarelika-0.5.5-debug-test.apk` предназначен **только для тестирования** механизма обновлений на установленной debug-версии 0.5.4 с тем же сертификатом подписи. Не является production-релизом.

Для проверки текущую `0.5.3` первоначально обновляют **один раз** до bootstrap `0.5.4` с встроенным адресом GitHub; дальше приложение должно обнаружить этот выпуск 0.5.5 при следующем запуске и предложить открыть загрузку в браузере.

Публично публикуются только APK и метаданные; исходников, личных рецептов, файлов БД, токенов и ключей подписи здесь нет.
